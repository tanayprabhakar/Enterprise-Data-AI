# Context: PII Redaction Pipeline

## Project Scope
This project aims to build an automated PII (Personally Identifiable Information) redaction pipeline for corporate filings. Specifically, the target is an IPO Red Herring Prospectus (RHP) containing dense financial tables, narrative prose, and embedded scans of identity cards (PAN and Aadhaar) [1, 2].

## Required PII Types to Detect
The pipeline must detect and redact the following entity types [1, 2]:
- Full Names
- Email Addresses
- Phone Numbers
- Company Names
- Physical/Mailing Addresses
- Social Security Numbers / Indian PAN
- Credit Card Numbers
- Dates of Birth
- IP Addresses
- Aadhaar Numbers

## Substitution Policy
- **No simple masking or bracketed tags** (e.g., no "[REDACTED]").
- Every detected entity must be swapped with a realistic synthetic value generated by `Faker`.
- **Referential Consistency**: The substitution must preserve referential consistency across the entire document. The same real entity must map to the exact same synthetic (fake) entity everywhere it appears [1].

## Execution Target
- **Environment**: A standalone Jupyter Notebook (`pii_redactor.ipynb`).
- **Runtime**: Designed to be executed on Google Colab using a T4 GPU runtime.
