Initial commit: PII Redaction Pipeline v1.0 for Indian DRHPs

Architecture & Capabilities:
- Deployed python-docx traversal engine (paragraphs, tables, images)
- Integrated presidio-analyzer (spaCy en_core_web_trf) with Faker('en_US') stateful mappings
- Added 7 Custom Pattern Recognizers (PAN, Aadhaar, DOB, Phone, CIN, SEBI Registration, PIN Code)

Edge-Case Hardening:
- Implemented .title() casing workaround and hardcoded keyword bypass ("WIDELY CIRCULATED", "NEWSPAPER") to mitigate transformer ALL-CAPS hallucinations on legal clauses
- Built overlapping span resolution algorithm to prevent string slicing corruption
- Integrated aggressive Anchor Regex in pytesseract OCR pipeline to sanitize glued artifacts and safely wipe dates/names preceding ID markers without NER reliance
- Filtered SEBI false positives using strict case-sensitivity evaluation
